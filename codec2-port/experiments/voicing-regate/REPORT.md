# VOICING-REGATE (раунд 2, идея B2): перцептуальный гейт FFT-free voicing

**Verdict: CONFIRMED** (для реальной речи) — расхождения FFT-free правила с
MBE-референсом перцептуально пренебрежимы end-to-end. На всех 6 речевых файлах
корпуса swap-версия (битстрим 1300 с нашим voicing) по всем метрикам ближе к
стоковому декоду, чем random-контроль с **тем же** флип-рейтом, а сдвиг
относительно оригинала — нулевой в пределах шума метрик: ΔESTOI(orig) −0.002
(знакопеременный, |Δ| ≤ 0.016), ΔWARP-Q(orig) −0.027 (у 6/7 файлов swap
*ближе* к оригиналу, чем сток!). FFT-free энкодер (трек-идеи B1/B2) — жив.

Проверенная гипотеза (оговорка раунда 1): 9.93% несогласий сидят на границе
неуверенности самого референса и потому перцептуально бесплатны. Предсказание
гипотезы «случайные флипы с тем же рейтом вредят больше» подтверждено на
каждой метрике и каждом речевом файле (три сида контроля).

## Сетап

- codec2 @ `310777b` (пин проекта), Release-сборка (gcc -O3) + `-DDUMP`;
  плюс отдельная сборка `-O2` для замера флоат-шумового пола.
- **Правило** — победитель раунда 1 (tree2), точные пороги из
  `experiments/voicing/results/summary.json` (не округлённые из REPORT):
  `v = (nacf_wo > 0.2638904) ? (r1r0 > -0.29466294) : (r1r0 > 0.845930125)`.
  Функции фичей скопированы из `experiments/voicing/features.py` (та же
  кадровка 320-сэмплового буфера, DC-снятие, двухкаскадный one-pole LP 1 кГц,
  ±15% окно лага вокруг P из дампнутого Wo). Дивергенции: считаются только
  две нужные правилу фичи; реконструкция референс-voicing скопирована
  без изменений и переверифицирована тем же selfcheck-гейтом (100% на всех
  файлах). Воспроизведение раунда 1 — **побитовое**: 9.93% несогласий overall,
  per-file совпадает до сотых (см. лог `rule.py`).
- **Подмена**: патч `voicing_override.diff` — codec2_encode_1300 после каждого
  `analyse_one_frame` заменяет `model.voiced` на k-й символ файла из env
  `C2_VOICING_OVERRIDE` (k = счётчик 10-мс кадров). Без env энкодер побитово
  стоковый. Кодирование: сток / swap (правило) / rand1..3 (контроль);
  декодирование всего — одним стоковым c2dec 1300.
- **Верификация подмены** (verify_bitstream.py, все проверки прошли на всех
  файлах): (а) voicing-биты стокового битстрима == независимо
  реконструированный референс из c2sim-дампов — доказывает совпадение
  кадровых сеток c2enc/c2sim И что патченный бинарь без env стоковый;
  (б) voicing-биты swap == решения правила, rand == контрольные;
  (в) все остальные 48 бит/кадр побитово идентичны во всех версиях.
  (Отдельная ловушка: расширение `.c2` даёт 7-байтовый файл-заголовок,
  который парсится как «лишний кадр» — используем headerless `.bit`.)
- **Random-контроль**: старт от стоковых решений, флипы в равномерно
  случайных позициях, количество = числу несогласий правила на этом файле
  (рейт совпадает точно), 3 сида. Random-флипы попадают в стационарные
  сегменты, где референс уверен; флипы правила — на 85% в ±2 кадрах от
  V/UV-границ (раунд 1).
- Корпус: все 7 `codec2/raw/*.raw` (14025 кадров), `testframes_700d` —
  синтетика (тоны), репортится отдельно.

## Результаты

### End-to-end против оригинала (главный тест)

| метрика (реальная речь, 6 файлов) | swap (правило) | random-контроль |
|---|---|---|
| ΔESTOI(orig) vs сток, среднее | **−0.0020** (от −0.013 до +0.016, знак гуляет) | **−0.0143** (минус на 5/6 файлов) |
| ΔWARP-Q(orig) vs сток, среднее | **−0.027** (swap ближе к оригиналу на 6/7) | — (см. прямой A/B ниже) |

Масштаб: сам кодек стоит ~0.45 ESTOI (0.38–0.59 у декода против оригинала) и
~2.3 WARP-Q; поправка от подмены voicing — на 1.5–2 порядка меньше и без
систематического знака. Random-контроль при том же рейте — стабильно минус.

### Прямой A/B: декод против декода (сток = референс)

Агрегат (среднее по 6 речевым файлам; полные per-file таблицы —
`results/summary.md`):

| версия | segSNR dB | ESTOI | LSD dB | NMR dB |
|---|---|---|---|---|
| swap (правило) | **1.23** | **0.8938** | **5.85** | **−7.6** |
| random-контроль (3 сида) | −1.62 | 0.8656 | 6.55 | −6.9 |

Swap лучше random по **каждой** метрике на **каждом** речевом файле
(ESTOI-разрыв 0.001–0.05; WARP-Q A/B: 1.54 против 1.67, ближе на всех
речевых). Порядок величин самих цифр обманчив, см. следующий пункт.

### Почему парные метрики декодов «плохие» у обеих версий

Фазы codec2 синтетические (перцептуально свободные по конструкции), но
**стейтфульные**: один флип навсегда декоррелирует фазовую траекторию
декодера, и waveform-разность |swap−сток| остаётся большой после первого
флипа даже там, где огибающие совпадают. Отсюда segSNR ~0–7 дБ и фоновая
спектральная разность 4–6 дБ у обеих версий — это цена фазовой памяти, а не
слышимая деградация (сам кодек к фазе глух). Санити: до первого
эффективного флипа декоды побитово совпадают (`first_divergent_frame` ==
суперкадр первого флипа на всех файлах). Перцептуально значимы
фазо-робастные метрики (ESTOI к оригиналу, WARP-Q) и **сравнение с
random-контролем на одинаковом рейте** — обе оси дают один ответ.

### Кто носитель остаточной разности (magnitude-домен)

Пер-кадровая лог-спектральная разность (20 мс, 100–3400 Гц) над фазовым
фоном 3.8–5.6 дБ: у кадров возле флипов 6.6–7.1 дБ; из кадров с SD > 3 дБ
46–53% лежат в ±2 кадрах от флипа-или-V/UV-границы (сами эти окрестности —
26–35% кадров). Т.е. остаточная сверхфоновая разность сидит на транзициях —
ровно там, где раунд 1 нашёл 85% несогласий, и где спор идёт о моменте
переключения, а не о звонкости сегмента.

### Флоат-шумовой пол (-O2 vs -O3)

Полные тракты -O2 и -O3 на hts1a **побитово идентичны** (и битстрим, и
декод): x86-64/SSE2 без -ffast-math не даёт переупорядочивания. Пол = 0,
критерий «под шумовым полом» вырождается — вердикт опирается на
random-контроль, как и предусматривала методика. Побочный калибр: WARP-Q
двух идентичных файлов = **0.515** (собственный пол метрики, DTW-стоимость
сигнала против себя) — на этой шкале A/B-расстояния 1.1–1.7 и Δ(orig)
±0.06 читаются правильно.

### Каверза: testframes_700d (синтетика)

35% флипов (систематика по r1r0 на тонах, известно из раунда 1); в прямом
A/B swap хуже random (ESTOI 0.187 против 0.194), ΔESTOI(orig) −0.073 — но
ESTOI на неречевом сигнале с ESTOI(orig, сток) = −0.02 бессмыслен, а
ΔWARP-Q(orig) = −0.010 ≈ 0. Вывод остаётся: для **речи** правило
перцептуально эквивалентно; для чистых тонов/DTMF-подобных входов — нет
(если такие входы важны, нужен отдельный guard, напр. по nacf_wo≈1).

## Что это значит для трека B

1. Гейт «перцептуальная эквивалентность voicing» (следующий kill-тест из
   REPORT раунда 1, п.2) — **пройден** на речевом корпусе: деградации
   end-to-end нет (нулевые Δ против оригинала), а структура ошибок
   (границы неуверенности) подтверждена как перцептуально дешёвая —
   random-контроль с тем же рейтом стабильно хуже.
2. FFT-free voicing-путь для энкодера B1/B2 (~сотни операций/кадр в связке
   с ASDF-питчем, см. раунд 1) можно закладывать в дизайн. Гейт для
   fixed-point реализации правила формулировать перцептуально: ΔWARP-Q и
   ΔESTOI против флоат-оракула ≤ random-контроля на измеренном флип-рейте
   (побитовый бюджет «флипы < 0.5%» из README §4 к этому пути неприменим —
   он для транслитерации, а не для альтернативного алгоритма).
3. Открытое: шумовые условия (раунд 1: conf-флипы в шуме даже ниже) и
   не-речевые входы end-to-end не мерялись; ABX живыми ушами — вне CI,
   опционально на вехе.

## Воспроизведение

```
cd codec2-port/experiments/voicing-regate
./run_all.sh    # клон+сборка (патч), дампы, правило, контроли, энкоды,
                # бит-верификация, декоды, WARP-Q, метрики, summary
# артефакты: results/{metrics.json,warpq.json,summary.md}; рабочие данные в
# work/ (gitignored); REGATE_WORK= переносит
```

Зависимости: gcc/cmake/make, git, python3 + numpy scipy pystoi. WARP-Q
(шаг 8, best-effort): `pip install librosa pandas soundfile tqdm joblib
webrtcvad-wheels && pip install --no-deps pyvad` (стоковый webrtcvad не
собирается с новым setuptools; pyvad дополнительно требует шимов numpy≥2 /
клиппинга — оба в `warpq_run.py`). Время: ~15 мин на 4 ядрах (из них
~10 мин WARP-Q).
