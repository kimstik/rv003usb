# error-injector: анализ чувствительности стадий (§4а-1) — первые ИЗМЕРЕННЫЕ бюджеты

Раунд 3. Механизм §4а-1 README («адаптивный вывод бюджетов вместо априорных
цифр») превращён из дизайна в числа: калиброванная ошибка каждого характера
инжектируется на границе каждой стадии **выбранной архитектуры** (не
легаси-декодера!), снимаются передаточные кривые «уровень ошибки → сквозные
метрики», из колен кривых выводится первая адаптивная таблица бюджетов
([`results/budgets.yaml`](results/budgets.yaml)).

## Стенд

- **Система под тестом** — рекомендованная связка simplification-map:
  трубный декодер, ступени **L0+L2(2500 Гц)+L4-0.50** (без дисперсии и
  джиттера — колено P2), питаемый реальными декодированными 1300-параметрами
  (c2sim `--rate 1300`, codec2 @310777b, оракул-пин общий с tube-ladder).
  Коэффициенты фильтра **всегда** перестраиваются из cos(LSP) — это G8-путь
  данных (проверка: |ak_rebuilt − ak_dec| ≤ 8.3·10⁻⁶ на дампах, конвенция
  lsp_to_lpc воспроизведена точно).
- Корпус: hts1a, hts2a, ve9qrp_10s (3 диктора, 22 с речи, 2242 кадра).
- Возбуждающий LFSR фиксирован во всех прогонах → любая дельта метрик
  атрибутируется инжекции. Выход сатурируется в ±32767 (как на MCU).
- Шумовой пол реализации (CLEAN2: та же система, другой seed LFSR):
  |ΔESTOI| до 0.009, LSD 5.7–6.4 дБ — это цена *другой реализации шума*,
  наши сравнения с фиксированным LFSR им не затронуты.

**Точки инжекции** (8 штук × 2–4 типа ошибки × 4–6 лог-уровней = 130
комбинаций × 3 файла = 390 синтезов):

| Точка | Сторона | Симулирует | Типы |
|---|---|---|---|
| coslsp | дек. | CSD/таблицы коэфф. = cos(LSP) | white, framemod, dc, worst (сжатие пар) |
| state | дек. | усечение guard-битов состояния IIR | white, framemod (пампинг), dc (перекос усечения) |
| pulsepos | дек. | квантование аккумулятора периода | white, qround, qtrunc |
| log2e | дек. | ошибка exp2-LUT на гейне | white, framemod, dc |
| mixfc | дек. | ошибка частоты кроссовера L2 | dc, white |
| mixnf | дек. | ошибка доли шума L2 (дБ) | dc, white |
| wo | энк. | относительная ошибка Wo | white, dc, framemod |
| lsphz | энк. | ошибка LSP в герцах | white, dc, worst |
| edb | энк. | ошибка энергии в дБ (по 40-мс блокам) | white, dc |

**Сквозные метрики**: LSD и огибающе-взвешенный NMR-прокси к чистому синтезу
(чистый эффект инжекции, нулевой лаг по построению), crest-Δ, segSNR, ESTOI
к оригиналу; WARP-Q к оригиналу (таймбокс: подмножество hts1a, 130 пар).
**Кванты колена**: ΔLSD ≥ 0.25 дБ, ΔESTOI ≥ 0.005, ΔWARP-Q ≥ +0.05;
колено = первое пересечение (лог-интерполяция), бюджет = колено / 4.

**Методологическая поправка по ходу**: для тайминговых точек (wo, pulsepos)
LSD/segSNR к чистому синтезу заражены дефазировкой импульсов (LSD 0.9 дБ при
джиттере Wo всего 0.05%, при ΔESTOI +0.0001) — окна видят импульсы на других
позициях без какого-либо перцептуального коррелята. Для этих точек колено
берётся только по перцептуальным метрикам; LSD остаётся диагностикой.
Это зеркальный урок к xcorr-предупреждению tube-ladder: **временны́е сдвиги
ломают и магнитудные метрики тоже**, если сравнивать с посэмпловым эталоном.

## Бюджетная таблица — главное (полностью в budgets.yaml)

| Стадия/тип | Колено (метрика) | **Бюджет** (=колено/4) | Инженерный смысл бюджета |
|---|---|---|---|
| coslsp/white | 4.3·10⁻⁴ (LSD) | **1.1·10⁻⁴ cos-ед.** | таблицы/CSD cos(LSP) нужны ~**12–13 бит** (8-бит таблица: rms 2.3·10⁻³ — 21× сверх бюджета) |
| coslsp/worst | 4.9·10⁻⁴ (LSD); ESTOI-колено 7.9·10⁻⁴ — вдвое раньше white | 1.2·10⁻⁴ | коррелированное сжатие пар перцептуально ×2 дороже белого — инвариант §4а-3 подтверждён числом |
| state/white | 2.1 LSB (LSD) | **0.53 LSB int16** | шум усечения на выходе ≤ полу-LSB → ≥1 guard-бит после сатурации масштаба; segSNR на колене = 33 дБ |
| state/dc | 3.2 LSB (LSD) | 0.79 LSB | перекос усечения дешевле шума → округление вместо усечения снимает вопрос |
| pulsepos/qround | 4.3 сэмпла (ESTOI) | **1.1 сэмпла** | **целочисленный аккумулятор периода с округлением легален с 4× запасом** |
| pulsepos/qtrunc | 2.2 сэмпла (ESTOI) | 0.55 | с усечением — уже нет: нужен 1 дробный бит либо округление |
| log2e/white | 0.033 log2 (LSD) | **0.0083 log2 ≈ 0.05 дБ** | exp2-LUT: относительная ошибка rms ≤ 0.6% — хватает ~8-бит мантиссы |
| mixfc/dc | 1.5% (LSD); ESTOI не пересёк даже +64% | 0.37% | кроссовер по перцепции почти свободен (ESTOI даже слегка растёт при сдвиге вверх) — LSD-квант здесь консервативен |
| mixnf | 0.38–0.41 дБ (LSD) | ~0.1 дБ | доля шума — обычная «энергетическая» точность |
| wo/white | 3.2% (ESTOI) | **0.81%** | шаг квантователя битстрима 1.6% сидит ПОД перцептуальным коленом 3.2% — консистентно |
| lsphz/white | 1.1 Гц (LSD) | **0.28 Гц** | int-Гц округление LSP (rms 0.289 Гц) садится **ровно на бюджет** |
| edb/white | 0.25 дБ (LSD) | 0.063 дБ | передаточный коэффициент дБ→LSD ≈ 1 (кривая это подтверждает: колено = квант) |

Пампинг (framemod) при равном **RMS** everywhere оказался ≈ эквивалентен
белому шуму по нашим метрикам (колени совпадают после нормировки на √2) —
с оговоркой, что ESTOI/LSD слабо чувствительны к модуляции 50 Гц; гейт
стационарности §4а-3 этим замером не отменяется, а остаётся единственным
детектором пампинга.

NMR-прокси линеен по лог-уровню на всех точках (то есть работает как
передаточная линейка): на LSD-колене coslsp он ≈ −40 дБ, на перцептуальном
колене ≈ −29 дБ — калибровка для будущего дешёвого гейта в параметрическом
домене (открытый пункт README №12).

## Измеренное vs априорное (payoff)

| Априорный бюджет (README §4) | Измерено | Вердикт |
|---|---|---|
| Wo RMS < 0.2% | колено 3.2%, бюджет 0.81% | **слишком строг ×4** — законный запас для целочисленного Wo-тракта |
| амплитуды < 0.3 дБ средн. | бюджет 0.056–0.063 дБ по ΔLSD-кванту; по чисто перцептуальному кванту (ESTOI-колено 0.83 дБ) — /4 = 0.21 дБ | **слишком слаб ×5 по LSD-кванту**; по перцепции — примерно верен. Вывод: 0.3 дБ не защищает гейт LSD 0.25 дБ по построению |
| LSP «прозрачность Paliwal–Atal» (~1 дБ SD) | LSD-колено 1.1–2.1 Гц, перцептуальное 8.3 Гц (white) | априорная формулировка была не числом; измеренное число — **0.28 Гц бюджета**, и int-Гц таблицы это ровно выполняют |
| segSNR(fixed vs float) > 25 дБ | state-колено сидит на segSNR ≈ 33 дБ | **слишком слаб ×2.5 по шуму** (8 дБ): гейт 25 дБ пропустил бы деградацию, видимую LSD-квантом |
| «FFT SNR > 60 дБ» (выброшен ещё в §4а) | эквивалентный шумовой бюджет стадий ≈ 45–52 дБ SNR | подтверждено: плоские 60 дБ были **слишком строги** — и при этом не защищали от спуров/корреляций (см. coslsp/worst) |

Отдельно к G8: red-team принял CSD-3-слагаемых с SD 0.35 дБ — это ВЫШЕ
нашего кванта 0.25 дБ. Противоречия нет: это *принятое упрощение* со своей
строкой леджера; бюджеты из budgets.yaml — про **неучтённые** ошибки
реализации сверх принятых. Но таблица показывает цену: у CSD-квантования
коэффициентов запаса на «прочие» ошибки уже не остаётся — остальным стадиям
жить в своих бюджетах.

## Самый большой сюрприз

**WARP-Q — основная метрика проекта — систематически слепа к возбуждающему
тракту и даже «награждает» его ошибки**: DC-смещение состояния фильтра
улучшает счёт до −0.19, грубое квантование периода (2-сэмпловая сетка) — до
−0.15, а сдвиг Wo на +12.8% — до −0.07. DTW-ядро метрики нормализует
темп/питч по построению. Следствие для CI: WARP-Q не может быть
единственным гейтом тайминговых стадий — ESTOI и параметрический домен
обязаны стоять рядом (в наших коленах WARP-Q не является управляющей
метрикой ни в одной строке таблицы). Второе место: феноменальная
нечувствительность позиции импульса (целочисленный аккумулятор с
округлением проходит с 4× запасом — дробная задержка L0 может быть
радикально упрощена).

## Ограничения и что дальше

- Бюджеты сняты **при одиночной инжекции**; кумулятивный леджер должен
  делить квант между одновременно живущими ошибками (сумма бюджетов ≠
  бюджет суммы; для белых шумов складываются мощности — грубая аддитивность
  есть, для коррелированных — нет).
- ΔLSD-квант 0.25 дБ управляет 6 из 9 точек; он заведомо жёстче
  перцептуальных метрик (в 4–30×). Это сознательный выбор «острого ножа»;
  если веха упрётся в него по циклам/флешу — таблица уже содержит
  перцептуальные колени для торга.
- WARP-Q на подмножестве (hts1a); спур/тон-инжекция (одиночный тон в
  спектре ошибки) не разворачивалась — покрыта worst-case coslsp частично,
  полный SFDR-гейт остаётся на механизме §4а-3.
- Тишина/DC/тон-стрессы (предельные циклы) — вне этого раунда, есть в
  ночном плане METRICS.

## Воспроизведение

```
./run_all.sh   # оракул (общий с tube-ladder) → дампы → 390 синтезов →
               # WARP-Q (hts1a) → results/budgets.yaml → plots/*.png
```
~20 мин на 4 ядрах контейнера; всё детерминировано (LFSR + фиксированные
seed'ы инжекции). Файлы: `inject_tube.py` (система под тестом + инжекторы),
`run_injection.py` (свип), `warpq_inject.py`, `knees.py` (колени → YAML),
`plots.py` (передаточные кривые, 9 PNG в `plots/`).
