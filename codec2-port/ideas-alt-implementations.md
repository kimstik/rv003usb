# Альтернативные имплементации: битстрим — контракт, всё остальное свободно

Принцип легальности: кодек обязан читать/писать валидные кадры codec2 — и только.
Референсный энкодер — лишь одна из валидных реализаций (его x86/ARM-сборки уже
расходятся побитово, апстрим допускает это в своих же тестах). Значит, и энкодер,
и декодер можно строить альтернативным путём, если сквозные метрики (§4/§4а
README) в бюджете. Маркировка: V = проверено в источниках/коде, P = правдоподобно
(стандартный DSP), S = спекулятивно, нужен эксперимент.

## A. Альтернативные движки синтеза (декодер)

**A1. Меандры вместо синусов — с компенсацией через треугольную систему.** (S→P)
Меандр частоты f содержит нечётные гармоники f, 3f, 5f… с весами 1/k. Ключ: для
гармонического сигнала 3f, 5f — это тоже гармоники Wo, т.е. «паразиты» ложатся на
полезные бины. Синтезируем L гармоник как линейную комбинацию ~L/2 меандров:
амплитуды меандров находятся обратной подстановкой верхнетреугольной системы
(на кадровой частоте, дёшево), а на частоте сэмплов остаются только сложения ±A.
Умножений в сэмпл-цикле — ноль. Вариант с треугольными волнами (спад 1/k²) лучше
обусловлен. Риски: связанность фаз внутри меандра (наши фазы и так синтетические —
проверить совместимость с мин-фазной моделью), обусловленность решения.
Kill-тест: хост-модель, кондиционирование матрицы + NMR vs эталонный синтез.

**A2. Walsh/Адамар-домен.** (P/S) FWHT на 512 точек = ~4.6k **сложений**, ноль
умножений. Уолш-вокодеры существовали в 1970-х. Спектр в базисе секвент,
коррекция Уолш↔Фурье — разреженная матрица. Радикально дружелюбно к RV32EC.
Kill-тест: энергия просачивания между базисами на реальных огибающих.

**A3. Импульсный поезд + формирующий фильтр (source-filter эквивалент).** (V/P)
Синусоидальный синтез с мин-фазой ≡ импульс на период питча через мин-фазный
фильтр огибающей. Один импульс + IIR порядка 10–20 = единицы MAC/сэмпл. Это
«floor-декодер» из README, но апгрейдируемый: смешанное возбуждение (импульс +
шум по полосам), фильтр из rate-K огибающей через кепстр→IIR. Лестница качества
между LPC-10 и полным синусоидальным синтезом.

**A4. Цикл-реплей (wavetable на период питча).** (P) Внутри кадра сигнал
периодичен → посчитать ОДИН период (до 160 сэмплов) раз в 20–40 мс и
воспроизводить фазовым аккумулятором с кроссфейдом на границах кадров.
Стоимость синтеза падает с 100 IFFT/с до 25–50 «пересчётов периода»/с.
Потеря: скорость обновления огибающей — измеримо.

**A5. Фазонепрерывный банк осцилляторов = смерть OLA.** (P) OLA существует потому,
что IFFT-кадры независимы. Осцилляторы с фазовыми аккумуляторами, живущими
сквозь кадры, не требуют ни окна, ни перекрытия → минус 2× работы в зоне
перекрытия и минус таблица окна. Комбинируется с A1/A4 и top-N.

**A6. Расщеплённый синтез по полосам.** (P) Верхние гармоники звонкой речи для
уха шумоподобны (MBE это и эксплуатирует полосным voicing). Декодер умнее
референса: гармоники <1.5 кГц — честные осцилляторы, выше — шейпленный шум от
LFSR даже в voiced-кадрах. Число осцилляторов падает в 2–4×. Битстрим не
меняется. Kill-тест: ABX/WARP-Q по границе расщепления.

**A7. Фазы Шрёдера — бесплатный бит запаса.** (P) Референс фазы синтезирует;
мы вправе выбрать СВОИ детерминированные фазы. Фазы Шрёдера минимизируют
крест-фактор суммы гармоник → ниже пики → +1 бит эффективного динамического
диапазона fixed-point тракта задаром. Kill-тест: слышимость vs референсные фазы.

**A8. Синтез сразу в PWM/1-бит домен.** (S) Не PCM→ЦАП, а пульс-плотность на
период (прецедент: 1-bit музыка на 003). Совместимо с A4: периодный wavetable
хранится уже как PWM-паттерн.

**A9. Гармоническая децимация.** (P) <1 кГц — все гармоники; 1–2 кГц — каждая
вторая с энергетической компенсацией √2; выше — шум (A6). Плавная ручка
качество↔циклы, при перегрузе — динамический top-N (graceful degradation).

## B. Энкодер без FFT вообще

**B1. Ключевой факт: для 1300/3200 битстрима FFT нужен только качеству voicing.**
(V) Передаются LSP+Wo+E+voicing. LPC — из автокорреляции (3.2k MAC/20 мс,
тривиально), энергия = R(0) через CLZ в log2 (бесплатно), питч — ASDF на 2 кГц.
Единственное, что давал 512-pt FFT — MBE-оценку voicing. Вопрос «энкодер без
FFT» сводится к вопросу «voicing без FFT».

**B2. Voicing без FFT.** (P) Стандартная связка: глубина нормализованного
минимума ASDF (аналог NACF из YIN/RAPT — уверенность питч-оценки И есть
voicing), + наклон спектра через первый коэффициент отражения r1/r0 (бесплатен
из уже посчитанной автокорреляции), + ZCR. Kill-тест: матрица ошибок voicing
vs MBE на корпусе; цена ошибки известна (клики) — гейт по флипам на уверенных
кадрах.

**B3. 700C-энкодер через IIR-мелбанк — прямо в домен rate-K.** (P, прецедент V)
newamp1 живёт на K=20 мел-точках. Вместо FFT→ресэмплинг: 20 полосовых IIR
2-го порядка на мел-центрах → энергии полос → log2 → снятие среднего → VQ.
Прецедент на самом 003: ch32v003_stt делает мел-банк в реальном времени.
VQ-поиск по int8-кодбуку — чистые int-MAC. Энкодер 700C целиком без FFT.

**B4. Ускорение VQ-поиска.** (P) Partial-distance elimination, отсечение по
неравенству треугольника с предвычисленными нормами, переупорядочивание
размерностей по дисперсии. Офлайн-реорганизация кодбука в дерево (LBG-split) —
декодер и битстрим не затронуты: индексы указывают в тот же кодбук.

**B5. Двухтемповый анализ.** (S) Питч раз в 40 мс + дешёвый трекинг-предиктор
между; огибающая раз в 20 мс. Потеря — измерима параметрическим доменом.

## C. Предвычисление по индексам битстрима (точно и бесплатно)

**C1. Wo-индексированные таблицы.** (P) Wo квантован в 7 бит = 128 значений.
Для каждого индекса офлайн предвычислить: L, приращения фазовых аккумуляторов
гармоник, параметры перехода. Вся пер-кадровая тригонометрия → выборка из
флеша. Точность: точная (таблица = квантователь).

**C2. Энергия 5 бит → сдвиг + таблица 32 записи.** (P) Аналогично.

**C3. Запечённый постфильтр.** (P) Среднее действие post_filter_newamp1 вшить
в копию декодерного кодбука офлайн (частично — фильтр действует на сумму
двух стадий VQ; остаток — дешёвая поправка). Нулевая цена в рантайме.

**C4. Целочисленные LSP в герцах.** (V-факт, P-приём) Кодбуки LSP — целые герцы.
Вести квантование/декодирование прямо в int-Гц, без float-радиан вообще.

## D. Классика fixed-point из наследия ETSI/ITU (не переизобретать)

**D1. Leroux-Gueguen / Schur вместо Levinson.** (V-классика) Стандартная замена
в fixed-point LPC (AMR/G.729): нет роста динамики промежуточных, нет делений
в рекурсии.

**D2. Деление через Ньютона на сдвигах** там, где осталось. (P)

**D3. Базовые операторы G.191 STL** как словарь макросов (сатурация,
L_mac и т.д.) — брать, не изобретать. (V)

## E. Мысли-скрепки

- **Декодер имеет право быть ЛУЧШЕ референса** (A6, C3): битстрим фиксирован,
  постпроцессинг — нет.
- Каждая идея A/B — это ступень лестницы с измеримой ценой; леджер потерь
  (§4а README) решает, что мержится.
- Первая тройка на kill-тесты (максимум информации на час работы):
  A1-хост-модель (обусловленность + NMR), B2-матрица voicing-ошибок,
  C1-таблицы Wo (безрисковая, можно сразу).
