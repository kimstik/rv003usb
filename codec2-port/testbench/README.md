# testbench — listening bench + experiment index

Two self-contained HTML deliverables, both regenerated by `./run_all.sh`:

| file | what it is | size |
|---|---|---|
| `out/listen.html` | the listening bench: 6 utterances x 5 conditions at mode 1300, **audio embedded as base64 WAV**, dense metric table per utterance (absolute values and deltas against the codec's own ceiling) | ~2.7 MB |
| `out/experiments.html` | the whole research tree in one offline page: every `REPORT.md` rendered, every `plots/*.png` inlined, TOC with one-line verdicts | ~5.9 MB |

Neither page makes a single external request, so both work from `file://`
and can be mailed as one attachment each.

## Usage

```sh
./run_all.sh                # everything (oracle build + fetch + matrix + pages)
./run_all.sh --no-neural    # skip NISQA/DNSMOS (no torch/onnx needed)
./run_all.sh --clean        # wipe build/ and out/ first
C2PORT_ROOT=/path/to/codec2-port ./run_all.sh   # research tree elsewhere
```

The bench reads `codec2-port/proto/` and `codec2-port/experiments/` and never
writes there. Everything generated lands in `build/` (the pinned codec2
checkout) and `out/`.

## The condition matrix

All conditions of one utterance consume the **same** `.c2` bitstream from
stock `c2enc 1300`, so B/C/E differ only in the decoder.

| id | chain | role |
|---|---|---|
| A | original 8 kHz input | anchor 0 |
| B | `c2enc` &rarr; `c2dec` (pinned float codec2 @310777b) | anchor 1 — the codec's own ceiling |
| C | `c2enc` &rarr; `c2tube` (our integer decoder, L0+L2+L4) | decoder under test |
| D | our encoder &rarr; `c2dec` | **pending round 4** — emitted as a pending row while `proto/encoder/` does not exist; `run_matrix.py` refuses to run silently once it does |
| E | `c2enc` &rarr; `c2tube_l0` (our decoder, rung L0 only) | Tier-2 "second grade", so the ladder is audible |

Condition E is built from the same source as C with two `#ifdef
C2TUBE_L0_ONLY` guards inserted by `mk_l0_variant.py`; `build_decoders.sh`
proves the guards are inert without the define by decoding a real bitstream
with both the guarded and a pristine `proto/decoder` build and comparing the
outputs byte-for-byte.

## Files

| file | role |
|---|---|
| `VERSION`, `build_oracle.sh` | pinned codec2 @310777b clone + host Release build (copied from `proto/decoder`, same pin) |
| `fetch_ext.sh` | best-effort download of the external ORIGINAL utterances from rowetel.com |
| `corpus.py` | assembles `out/corpus/*.raw` + `manifest.json` (trim to whole 40 ms frames, cap 8 s, provenance, sha256) |
| `mk_l0_variant.py` | derives the build-switchable decoder source into `out/build/src/` |
| `build_decoders.sh` | builds `c2tube`, `c2tube_l0`, `c2tube_pristine` + the inertness check |
| `run_matrix.py` | runs the matrix, writes `out/wavs/*.wav` and `out/results/bench.json` |
| `metrics.py` | ESTOI / LSD / segSNR in the project's published conventions, plus the alignment policy |
| `neural.py` | NISQA v2 + DNSMOS P.835, degrades gracefully to "column omitted" |
| `mdlite.py` | ~150-line Markdown&rarr;HTML renderer (headings, tables, lists, code, flattened links) |
| `make_listen.py`, `make_experiments.py` | the two page generators |

Committed outputs: `out/listen.html`, `out/experiments.html`,
`out/results/*.json`, `out/corpus/manifest.json`. Generated audio, the oracle
checkout and the host binaries are gitignored.

## Metric conventions (short form; the pages carry the long form)

* **ESTOI** vs the original, `pystoi` extended, at the single constant lag
  that maximises ESTOI over |lag| <= 256 samples. The correlation-peak lag of
  `proto/decoder/validate.py` is deliberately not used — it is phase-sensitive
  and mis-locked on the noisy utterance (mmt1 C: +144 instead of ~-100,
  ESTOI 0.328 -> 0.186). Absolute values therefore run slightly higher than
  the same names in `proto/decoder/REPORT.md`; rankings are unchanged.
* **LSD** vs condition B, `experiments/tube-ladder/metrics_ladder.py`
  convention (160-sample Hann on the 10 ms grid, 100–3700 Hz, -40 dB gate),
  at the LSD-optimal lag.
* **segSNR** vs condition B, `experiments/oracle/metrics_signal.py`
  convention, at the same lag. **Weak by construction**: `c2dec` uses phase0
  IFFT+OLA and `c2tube` is a free-running IIR tube, so this column measures
  phase disagreement that is largely inaudible.
* **NISQA / DNSMOS** are reference-free and were trained on wideband natural
  speech; on 8 kHz vocoded speech their absolute values are depressed and are
  not MOS. Per `experiments/metrics-adequacy`, read the deltas only.

## Corpus

Four utterances come from the pinned codec2 `raw/` directory
(hts1a, hts2a, kristoff, ve9qrp_10s) and two are downloaded as ORIGINAL
(uncoded) audio from David Rowe's codec2 pages
(`mmt1`, `cq_ref`) — all URLs are printed in `out/listen.html`. The blog
pages also host per-mode A/B files, but those are already vocoded and cannot
serve as bench input. `fetch_ext.sh` also downloads the site's `hts2a.wav` as
a provenance cross-check: it is byte-identical to the repo's `raw/hts2a.raw`.
